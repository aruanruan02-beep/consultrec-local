# 逐字稿交互待办

## 已实现：点击段落同步主播放器

- 逐字稿段落不再显示“播放本段”文字按钮。
- 点击任一逐字稿段落时，将页面顶部主音频播放器的进度同步到该段的 `start` 时间，但不自动播放。
- 保持使用同一个主播放器，不为每个段落创建独立播放器或播放控件。
- 用户随后手动点击主播放器的播放键时，将从已同步的段落起点开始播放。

## 保留：批量设置说话人

- 在编辑任一段的说话人时，保留现有的确认弹窗。
- 弹窗默认只修改当前段；用户可勾选“批量修改全文中所有同一旧 speaker 标签”。
- 勾选批量修改后，所有 speaker 与当前段修改前标签相同的段落，统一替换为新标签。
- 此功能适用于 `未确认`、`说话人 1`、`说话人 2`、`咨询师`、`来访者` 等现有标签；只比较和替换 speaker，不改动文字或时间范围。
- 保持该选项默认不勾选，避免一次误操作覆盖全文角色标记。

## 保留：编辑框回车拆分段落

- 在逐字稿文本编辑框内，按 `Enter`（不按 `Shift`）时，以当前文本光标位置拆成前后两个编辑段；`Shift + Enter` 保留为普通换行。
- 前段保留光标前文字，后段保留光标后文字；后段继承原段的 speaker，并自动把编辑焦点移到后段开头。
- 拆分必须同步拆分音频时间范围，两个新段应连续覆盖原段且不重叠。
- 保留既有规则：按光标前后文字长度比例估算时间切点；前后两段据此连续覆盖原段时间范围。
- 当前不需要按主播放器位置拆分时间。若以后另做“按播放位置拆分”，应作为独立操作，不改变回车拆分的行为。

## 已确定：清空文本删除段落

- 编辑中的某段文字被清空（包括仅剩空白字符）时，直接从 `edited_segments` 删除该段。
- 删除不自动合并相邻段，也不调整相邻段的时间范围。
